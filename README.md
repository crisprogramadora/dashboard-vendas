# 📊 Análise de Desempenho de Vendas

## Visão Geral do Projeto
Projeto desenvolvido para simular um processo de extração e agregação de dados em SQL, seguido por uma análise de desempenho no Power BI. O objetivo foi fornecer insights acionáveis sobre os drivers de receita e a distribuição de lucro.

## Perguntas de Negócio Respondidas
1. Qual a distribuição de lucro entre as regiões e segmentos de clientes?  
2. Quais as Top 5 Subcategorias de produtos em termos de faturamento?  
3. Como as vendas evoluíram ao longo do tempo (tendência mensal)?

## Ferramentas Utilizadas
- Kaggle (Obter os Dados e Configurar o SQL Básico)
- DB Browser for SQLite (Simulação de Banco de Dados)
- Power BI (Visualização)

## Principais Descobertas
- Distribuição de Lucro: Identificamos que determinadas regiões e segmentos de clientes concentram maior rentabilidade, sugerindo oportunidades de foco estratégico.
- Top 5 Subcategorias: As subcategorias com maior faturamento representam uma parcela significativa da receita total, sendo essenciais para decisões de estoque e marketing.
- Tendência Mensal de Vendas: A análise temporal revelou sazonalidade nas vendas, com picos em determinados meses que podem ser explorados em campanhas promocionais.

## Observações
- O projeto é uma simulação com dados fictícios, voltado para fins educacionais e de demonstração.
